# 别回头 / Don't Look Back

一个用纯前端做的沉浸式恐怖体验：**单页、无依赖、无外部音视频素材**，所有声音都由 Web Audio 实时合成。

线上地址：<https://chen7622132.github.io/dont-look-back/>

## 它做什么

打开页面后不需要任何操作：

1. **0–1.5s** 全黑，只有极低频的压迫感（55Hz 拍频 + 8kHz 耳鸣层）
2. **1.4s** 一张惨白的脸从黑暗里浮出来，只有 17% 的不透明度——你得眯着眼才看得清
3. **2.0s** 眼睛先亮起来，脸以几乎察觉不到的速度向镜头靠近
4. **3.7s** 声音和画面被一起抽走（静默剥夺）
5. **4.1s** 突脸：单帧反色 → 满屏的脸 → 尖叫 → 手机震动
6. **之后** 进入猎捕模式，每隔 6–17 秒随机从正面／左侧／右侧扑一次

另外：手指在屏幕上移动，它的视差会跟着你；**晃一下手机，它会立刻扑上来**；点一下屏幕也会。

第二次打开时不再给你准备的时间——它记得你来过。

## 用到的技术手法

| 手法 | 实现 |
| --- | --- |
| 17Hz 级次声铺垫 + 8kHz 高频尖叫的对比 | Web Audio 「振荡器 + 带通噪声 + 波形整形失真」，无音频文件 |
| 惊吓三段式（铺陈 → 误导 → 突袭） | 先抽走声音与光，再给 0.6s 纯黑，最后一帧内推满 |
| 视觉 3-2-1 法则 | 慢推 → 定格留白 → 极短黑帧 → 切出主体 |
| 边缘视觉惊吓 | 第二次突脸从画面右侧横向切入 |
| 单帧反色 | `mix-blend-mode: difference` 通路 24ms |
| **液化扭曲** | 自写 GLSL：两层 value-noise 推动 UV，脸像被拉扯的橡胶 |
| **万花筒** | 极坐标分段镜像，段数在 0.4s 内从 3 涨到 7，脸碎成多头 |
| **音频驱动视觉** | `AnalyserNode` 取时域 RMS，直接喂给 shader 的扭曲强度——叫得越尖，脸扭得越狠 |
| **癫狂尖笑** | 10–13 个锯齿脉冲，每个自带 45ms 音高上滑，音高逐次抬升，叠一层 1.85kHz 气声 |
| **疯狂骤停** | 疯到 0.80s 时全部归零，回到一张干净的脸 |
| 胶片颗粒 | 每帧生成 240×N 噪点写入 canvas，`mix-blend-mode: overlay` |
| 暗部保留 | 只靠 `brightness/contrast` 控制，不压死黑，暗处仍有细节 |
| 抽搐抖动 | 突脸期间对内部视差层施加 `steps(1,end)` 的 transform 动画 |
| 设备联动 | `deviceorientation` 控制视差，`devicemotion` 触发惊吓，`navigator.vibrate` 震动 |

## 安全提示

页面包含**突发惊吓、强光单帧闪烁与高分贝音效**。

- 有心脏疾病、高血压、光敏性癫痫者请勿打开
- 不要在开车、走路、戴耳机睡觉时打开
- 想退出：连点屏幕**右下角**三次，或按 `Esc`

## 本地运行

```bash
python3 -m http.server 8899
# 打开 http://127.0.0.1:8899
```

声音需要一次用户交互才能解锁（浏览器策略），所以第一声可能会静音——视觉上的惊吓不受影响。
